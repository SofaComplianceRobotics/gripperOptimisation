# Lab ShapeOPT runtime dependencies.
#
# Only packages the lab itself needs and sofaopt does NOT already bring in —
# cadquery/gmsh/svg.path/beziers/scipy are geometry-generation-only, nothing
# sofaopt touches. install_deps.py always installs sofaopt[dashboard,preview]
# first, so optuna/cmaes/dash/plotly/pyvista (and matplotlib, pulled in by
# pyvista) are already resolved by the time this file runs. Re-pinning any of
# those here just makes pip install a version, then immediately uninstall it
# for the one sofaopt already chose — wasted bandwidth and noisy "Attempting
# uninstall" logs for no behavioural difference, since the lab has no exact-
# version requirement on any of them.
#
# Installed into runtime/modules/site-packages by build_bundle.ps1 so the lab
# is self-contained and needs no setup on the target machine.
#
# Sofa / SofaPython3 is provided by the emio-labs install, not pip.
# OCP, ezdxf, nlopt, vtk are pulled in transitively via cadquery.
#
# numpy is not pinned in THIS file: neither cadquery nor cadquery-ocp declares
# a numpy dependency at all (OCP is a pybind11/OCCT wrapper, no numpy C-API
# use), so nothing here needs a specific version. It is pinned instead in
# tools/constraints.txt (numpy==1.26.4), which every install path passes as
# `pip install -c` - because install_deps.py / install_dev.ps1 install into the
# shared emio-labs SOFA Python next to emioapi (Requires-Dist: numpy==1.26.4)
# and the other labs, and an unconstrained sofaopt install would otherwise pull
# numpy 2.x and break the Emio hardware link.
#
# cadquery is held at 2.4.0 (matches constraints.txt) - 2.7.0 drags in
# cadquery-ocp 7.8 + vtk 9.3, a heavier swap than the shared env needs.

cadquery==2.4.0
gmsh==4.15.0
svg.path==7.0
beziers==0.6.0
scipy==1.15.3
